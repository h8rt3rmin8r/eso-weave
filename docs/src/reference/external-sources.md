# External and Project Sources

These external sources define the ESO integration context:

- [esoui/esoui](https://github.com/esoui/esoui) publishes ESO user-interface
  source and Lua API definitions. ESO Weave observes its `live` client-version
  file as an addon API bump signal.
- [ESOUI](https://www.esoui.com/) is the ESO addon community and index.
- [ESOUI Wiki](https://wiki.esoui.com/) provides human-readable ESO Lua API
  documentation.
- [The Elder Scrolls Online](https://www.elderscrollsonline.com/) is the official
  game site.
