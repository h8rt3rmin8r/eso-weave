### File selection

- **Full-color banner**: horizontal wordmark for documentation headers and wide identity placements. [Download the full-color banner](../assets/brand/eso-weave-banner.png).
- **Badged mark**: universal reduced icon on dark, light, and unpredictable surfaces. [Download the badged mark](../assets/brand/eso-weave-mark.svg).
- **Badge-less glyph**: owner-approved carets for controlled dark lockups. [Download the badge-less glyph](../assets/brand/eso-weave-glyph.svg).

The files `eso-weave-logo-clear.png` and `eso-weave-logo-white.png` are generated compatibility outputs, not masters. The authoritative SVG masters remain byte-identical to the kit.

### Reproduction rules

- Preserve aspect ratio. Never stretch, compress, rotate, outline, or add effects.
- Keep clear space of at least eight units on the 100-unit logo grid.
- Minimum sizes are 32 CSS pixels for the badged mark, 160 CSS pixels for the horizontal lockup, 144 CSS pixels for the stacked lockup, and 120 CSS pixels for the wordmark. Use the reduced mark below 32 pixels.
- Do not recolor the authoritative glyph or mark.
- Do not place the badge-less glyph on a light or uncontrolled surface.
- Never add an artificial crossing overlay, knockout, outline, or substrate separator to a single-ink derivative.
- Do not combine ESO Weave and ShruggieTech marks into one lockup.

Bright teal fails as text on the light background. Light interfaces use `#986000` for action, focus, link, and emphasis roles. White text on teal also fails, so dark teal fills use black text.

Product resource meters retain distinct health, stamina, magicka, and ultimate colors. These are data-visualization roles, not replacements for general semantic actions, and each pair remains contrast-tested.

## Typography

- Display: Inter Medium 500 and SemiBold 600.
- Body and labels: Inter Regular 400 and Medium 500.
- Technical metadata: Geist Mono Regular 400 for identifiers, timestamps, paths, status metadata, code, and hashes.
- Keep framework fallback fonts after the approved family for symbols and uncommon glyphs.
- Do not request undeclared weights or fetch a font at runtime.

Both the application and offline documentation bundle these files under their local asset roots with the SIL Open Font License notice.

## Interface grammar

- Spacing scale: 4, 8, 12, 16, 24, 32, 48, and 64 logical units.
- Control radius: 8 points. Card and dialog radius: 12 points.
- Interactive response target: at least 44 by 44 logical points, including compact layouts.
- Focus: visible 2-point ring with a 2-point offset where the renderer supports it.
- Status: pair color with text or a distinct shape.
- Motion: honor reduced-motion preferences.
- Contrast: at least 4.5:1 for normal text and 3:1 for required non-text boundaries.

The product owns screen composition, native window behavior, and domain data visualization. The component recipes govern shared control semantics and state behavior.
