# Archived Build Plans

This directory preserves completed ESO Weave build plans as historical records.
Their original prose and embedded status fields describe the repository at the
time each plan was written. The disposition table below is the current authority
for lifecycle status.

Every legacy plan is Complete because its planned implementation slices have a
committed spec package and merged repository implementation. Every plan is also
Archived because none directs the current work sequence. The current plan lives
in [`docs/project/build-plans`](../../project/build-plans/README.md).
