# Documentation Syntax Highlighting

S087 keeps code examples accurate, legible, selectable, and offline in the one
mdBook documentation build used by GitHub Pages and the bundled application.

## Source inventory

The maintained corpus contains 23 fenced blocks:

| Identifier | Count | Meaning |
| --- | ---: | --- |
| `bash` | 12 | Prompt-free command lines copied directly by readers |
| `powershell` | 3 | Windows PowerShell commands, including two list-nested maintenance examples |
| `text` | 8 | Deliberately non-executable formulas, flows, paths, maps, and ESO slash commands |

The eight plain blocks are bound in documentation policy by source page, exact
content SHA-256, and rationale. A new or edited plain block fails until its
classification is reviewed. Missing identifiers, unknown identifiers, and the
former `console` and `sh` aliases also fail. The aliases are not forbidden in
general Markdown; they are inaccurate for this exact prompt-free corpus because
their bundled grammars emit no useful token spans.

## Runtime boundary

mdBook 0.5.4 supplies Highlight.js 10.1.1, its structured grammars, and its three
local palette files. The ESO Weave theme script registers two bounded grammars
into that same runtime after `book.js`:

- the command grammar distinguishes executable, option, path or placeholder
  value, variable, number, string, comment, and punctuation forms; and
- the PowerShell grammar distinguishes cmdlet, switch, path or placeholder
  value, variable, keyword, number, string, comment, and punctuation forms.

Only `language-bash` and `language-powershell` nodes are re-highlighted. Each
node carries an idempotence marker and preserves its pre-highlight text. No
prompt is inserted, no second highlighter is loaded, and no network request is
made.

## Theme and accessibility contract

Project-owned token variables cover navy, light, coal, ayu, and rust. The custom
stylesheet loads after mdBook's palettes and sets the code background plus all
meaningful token roles to colors with at least 4.5:1 contrast.

The generated browser smoke exercises real multiline Bash and PowerShell
block, an intentional plain block, and a JSON probe from the bundled grammar in
all five themes at 320 and 1280 CSS pixels. Each of the 40 observations checks:

- `pre > code` semantics and exact runtime text preservation;
- a successful selectable range;
- code-local horizontal scrolling without page-level overflow;
- the required token roles, or zero spans for plain text; and
- computed token contrast against the active code background.

Static generated policy separately verifies source-to-output language order and
the local hashed runtime, palette, and extension assets. Release builds run the
same mdBook build and embed those generated bytes recursively. General table and
page responsiveness remains with issue #127; S087 owns only overflow introduced
by highlighted code blocks.
