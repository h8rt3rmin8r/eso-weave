## Description: Minimal screen-signal beacon managed by ESO Weave. It renders small color blocks that encode load status, fishing state, server latency, the active weapon bar with each bar's weapon class, the player's combat state, which native game menu or text field is open, the player's health, stamina, and magicka as percentages, whether the player is mounted, how long each action slot the game exposes a cooldown for (the five skills and the ultimate) has left before it can be used again, and the active quickslot's remaining cooldown and the identity of the item in it. It has no settings, no user interface, and no saved variables. Do not edit or publish; it is installed and removed by the ESO Weave application.
