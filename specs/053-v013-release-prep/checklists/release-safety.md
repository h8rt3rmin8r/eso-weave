# Release Safety Checklist

- [x] No version rollover occurs in the feature pull request.
- [x] No tag or GitHub Release is created.
- [x] No packaged asset is generated or uploaded.
- [x] Highlights make no unverified live-behavior claim.
- [x] Full engineering history remains available in the changelog.
- [x] The generated link targets the immutable v0.13.0 tag.
- [x] Publication still requires explicit post-merge authorization.
