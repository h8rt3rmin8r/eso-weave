# Requirements Checklist

- [x] Reader, contributor, and maintainer journeys are independently testable.
- [x] The authoritative source tree and deferred migration boundary are explicit.
- [x] Exact tool pins and immutable action pins are required.
- [x] Broken links, navigation completeness, case, offline assets, and subpath
  behavior have measurable gates.
- [x] Pull-request and main deployment permissions are separated.
- [x] Accessibility outcomes are testable without overstating conformance.
- [x] Generated output and dependency lifecycle boundaries are explicit.
- [x] The architecture decision and pinned-artifact governance record are required.
- [x] No unresolved clarification remains under the autopilot decision policy.
