# Contract: Documentation Figure System

## Inventory contract

The canonical corpus contains exactly 20 meaningful image placements: 11 screenshot or illustration placements, four Markdown flow diagrams, and five brand examples. Each meaningful placement has a non-empty alternative and becomes one trigger. The landing wordmark is the sole decorative placement, retains `alt=""`, and never becomes interactive.

Every screenshot or illustration figure has one adjacent caption. Each brand surface has one group caption associated with every image inside that surface. Flow diagrams retain their existing adjacent prose equivalents.

## Runtime enhancement contract

The checked-in theme script initializes once per document. It recognizes only the established screenshot, diagram, illustration, and brand selectors. Raw HTML images are wrapped in semantic buttons. For Markdown diagrams, mdBook's generated checkbox label and duplicate clone are removed after preserving the meaningful primary image.

Every trigger:

- is a native button;
- carries `data-docs-figure-trigger` and one idempotence marker;
- has the accessible name `Expand image: <source alternative>`;
- presents a persistent visible `Expand image` affordance; and
- retains the original local image and presentation classes without a second visual copy.

One `dialog[data-docs-figure-dialog]` is appended only when meaningful images exist. It contains one close button, one decorative visual image, and one optional cloned caption. No third-party or mdBook modal remains active beside it.

## Modal lifecycle contract

Pointer, Enter, and Space activation of a trigger opens the native modal. Before `showModal`, the dialog receives the source alternative as its accessible label, the image source and intrinsic dimensions, and an optional caption clone as `aria-describedby`. Focus moves to the close button.

Escape, the close button, or a pointer event whose target is the dialog backdrop closes it. Native modal behavior prevents interaction with the background and contains sequential focus. The close event returns focus to the exact invoking trigger and clears transient caption and source state.

Repeated initialization creates no additional trigger, wrapper, listener, or dialog.

## Geometry and presentation contract

The dialog image uses auto dimensions with viewport maxima. It may shrink but never exceeds its decoded natural width or height and never changes aspect ratio by more than 1.5 percent. Portrait and landscape cases remain contained at 320 and 1280 CSS pixels.

Triggers preserve the established inline figure widths and grid positions. Their persistent text affordance, pointer cursor, hover treatment, and focus-visible outline remain readable in light and dark themes and do not rely on color alone.

## Caption contract

Screenshot and brand captions share a `0.9em` body-relative font size, computing to 14.4 pixels, and at least `1.5` line height. Component rules retain their border, padding, and surface-appropriate inherited color. Complete captions remain at least 4.5:1 against their backgrounds in navy, light, coal, ayu, and rust. Strong brand lead-ins remain bold; complete captions are not italicized.

Captions remain unclipped, wrapping, and semantically inside their figures. The dialog clone preserves the caption markup and becomes the active modal description without replacing the source caption.

## Delivery and print contract

The figure system uses only checked-in CSS and JavaScript already included by mdBook. It performs no network request and adds no dependency. GitHub Pages and bundled offline documentation consume the same generated bytes.

Without JavaScript, authored images and captions remain static and readable. In print, trigger chrome and the persistent affordance are hidden, the trigger behaves as a neutral block wrapper, and the shared dialog is never printed.

## Evidence contract

Source and generated policy validate the exact inventory, selector boundary, idempotent native-dialog script contract, caption treatment, print neutralization, and absence of remote dependencies.

The hidden-browser smoke uses one directly spawned hidden Chrome-compatible process. Five actual generated-page cases run in navy and light at 320 and 1280 CSS pixels. The receipt proves actual post-script controls, one dialog, no mdBook modal remnants, trusted pointer hit testing, keyboard open and close paths, forward and reverse sequential focus containment, initial and returned focus, native modal state, accessible label and description, intrinsic geometry, viewport containment, source and modal caption size and contrast, both brand surfaces, and no page-level overflow introduced by the figure system. Dedicated generated-page observations also prove 200 percent browser scale, print media, and blocked-script static rendering.
