# Dashboard Layout Safety Checklist

**Purpose**: Protect sizing, accessibility, and existing action behavior

- [x] Expanded cards have equal outer width and height in both arrangements
- [x] Wide growth is symmetric and contains no independent column cap
- [x] Collapsed System and State always forces top-down order
- [x] Re-expansion immediately restores width-driven layout
- [x] Collapse transitions cannot overlap the open log or ratchet minimum size
- [x] Skills remains below the complete dashboard
- [x] All controls share the trailing interaction-column origin
- [x] Lifecycle buttons are equal-sized and at most two share one row
- [x] Install, update, uninstall, and confirmation semantics are unchanged
- [x] Dynamic values use flexible width and expose full keyboard detail
- [x] Resource grouping has one post-group gap for three or four meters
- [x] Required labels are exact and prose remains sentence-cased
- [x] Toggle controls have meaningful accessible names
- [x] Full constitution safety suites pass
