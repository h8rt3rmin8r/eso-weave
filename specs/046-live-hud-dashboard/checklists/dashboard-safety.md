# Dashboard Safety Checklist

**Purpose**: Protect truthful state, accessibility, sizing, and sealed surfaces

- [x] Inactive ESO cannot display Gameplay, Ready, or remembered live values
- [x] Active ESO plus missing signal cannot look inactive or healthy
- [x] Observed zero remains numeric and distinct from missing data
- [x] Low derives only from an enabled configured resource watch
- [x] PixelBeacon install and signal states render separately
- [x] Fishing and auto-potion show request and effective state together
- [x] Every meaningful color has text, shape, or fill-length redundancy
- [x] Text contrast is at least 4.5:1 in both themes
- [x] Meaningful meter graphics are at least 3:1 against adjacent colors
- [x] Narrow and wide layouts preserve Live HUD first
- [x] Responsive containers do not contaminate intrinsic minimum width
- [x] Log never overlaps dashboard or Skills in either layout
- [x] Skills source block and intent behavior remain unchanged
- [x] Managed-marker uninstall guard and confirmation remain unchanged
- [x] Full constitution safety suites pass
