# Quickstart: Validate Ultimate Auto Potion Resource Watch

## Focused automated validation

1. Run `cargo test --test potion` and confirm exact Ultimate boundary, unavailable-evidence, mixed-watch, migration, round-trip, and diagnostic tests pass.
2. Run `cargo test --test app_view_model --test app_strings --test app_ui_sizing` and confirm routing, status copy, settings labels, controller refresh, and modal sizing pass.
3. Run the repository documentation gates and confirm all Auto Potion references describe four watches and direct current-over-maximum normalization.

## Manual settings pass

1. Open Settings and find Auto Potion.
2. Confirm Health, Magicka, Stamina, and Ultimate appear as four consistent rows.
3. Navigate to Watch Ultimate by keyboard, toggle it, and set 0, 35, and 100 without leaving the accepted range.
4. Apply, reopen Settings, and confirm the value persists without clipping, overlap, or inaccessible help text.
5. With a synthetic or live fresh observation, confirm an Ultimate trigger names Ultimate and the threshold in the main status.

## Safety inspection

1. Confirm the diff does not change addon files, Pixel Bus protocol geometry, native action vocabulary, cooldown policy, retry policy, or input backend code.
2. Confirm the worker supplies `weave.ultimate()` directly beside current resources and quickslot state.
3. Confirm retained HUD presentation never enters `PotionReadings`.
4. Confirm unknown current, unknown maximum, zero maximum, signal loss, and non-active world fixtures emit no attempt.
