# Research: Documentation Syntax Highlighting

## Current evidence

- The corpus contains 23 fences, including two PowerShell fences nested under the Screenshot Maintenance ordered list: 7 `console`, 3 `powershell`, 1 `sh`, and 12 `text`.
- Twelve blocks are prompt-free executable commands. Eight `text` blocks are deliberately plain formulas, flows, paths, directory maps, or ESO slash-command lists.
- mdBook 0.5.4 bundles Highlight.js 10.1.1. It registers Bash with `sh`, Shell Session with `console`, and plaintext with `text`, but does not register PowerShell.
- `console` is recognized but wrong for the current commands because the Shell Session grammar expects prompts. The bundled Bash grammar also yields no spans for the exact argv-only command examples.
- Raw generated HTML contains semantic `pre > code.language-*` elements. Highlight.js creates token spans only after scripts execute in a browser.
- `book.js` attempts highlighting before additional JavaScript loads. A local extension therefore must register its grammars and selectively re-highlight owned blocks after that first pass.
- The current navy red token is 4.46:1 against the code background. Other bundled addition and deletion colors also fail AA in some supported themes.
- mdBook already supplies selectable block code with code-local horizontal overflow. The existing S086 hidden-browser smoke provides the safe loopback, CDP, deadline, and cleanup seams needed to verify it.
- Release builds independently run the same mdBook build and recursively embed generated bytes, but the release manifest does not explicitly require the highlight runtime and palette files.

## Decision: accurate source labels plus bounded local grammars

Correct all prompt-free executable blocks to the standard `bash` identifier. Keep `powershell` for PowerShell and `text` for explicitly authorized plain content. Register project-local command and PowerShell grammars into mdBook's existing `hljs` object, then re-highlight only `.language-bash` and `.language-powershell` blocks.

This preserves accurate, portable source metadata and one runtime while providing the token roles the exact command corpus needs. Adding prompts solely to activate Shell Session would damage copy-ready examples.

## Decision: content-addressed plain exceptions

Store the eight plain exceptions as path, exact content SHA-256, and rationale records. Reject any unlisted or changed `text` block, as well as missing, unknown, `console`, and `sh` identifiers.

Line-only allowlists drift when prose moves. Path-only allowlists let executable content silently replace a diagram. Content identity forces a conscious review when meaning changes.

## Decision: runtime evidence for tokenization

Static generated policy verifies source-to-output fence count, order, and language classes plus required local assets. The existing browser smoke verifies token spans after JavaScript, exact text preservation, semantic nesting, selection, horizontal scrolling, page containment, and computed contrast.

A generated JSON probe exercises mdBook's bundled structured grammar without adding a contrived reader-facing sample.

## Decision: project-owned theme palette

Override the relevant Highlight.js token classes through the existing custom stylesheet for dark (`navy`, `coal`, `ayu`) and light (`light`, `rust`) surfaces. Policy checks every declared token against the supported background family, while the browser matrix checks computed styles in all five active themes.

## Alternatives rejected

- **Fence renaming only**: Bash and Shell Session both produce no useful spans for the exact argv-only commands.
- **Prompt-prefixed sessions**: copying would require readers to remove prompt characters.
- **Second highlighting runtime**: duplicates parsing, theme, CSP, package, and offline responsibilities.
- **Full mdBook template override**: allows earlier registration but couples the project to upstream HTML for two small grammars.
- **A separate browser-smoke program**: duplicates substantial server, process, protocol, and cleanup code.
- **Screenshot or pixel-golden checks**: brittle across browser builds and weaker than computed semantic, text, overflow, and contrast evidence.

## Scope handoff

S087 owns syntax-generated overflow only. Issue #127 remains the owner of general table responsiveness and page-level overflow. No release verification can block this repository-backed completion.
