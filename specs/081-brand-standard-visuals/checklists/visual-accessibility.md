# Visual and Accessibility Checklist: Brand Standard Visuals

**Purpose**: Define the evidence needed for the visual Brand Standard.

**Created**: 2026-09-10

**Feature**: [spec.md](../spec.md)

## Approved Assets

- [x] Banner, badged mark, and glyph authorities are identified.
- [x] Surface permissions and prohibited light-surface glyph use are explicit.
- [x] Compatibility raster status is explicit.
- [x] Byte identity is required for every published copy.

## Palette Access

- [x] Every dark and light row requires a chip.
- [x] Every chip requires role and hexadecimal text in its accessible name.
- [x] Visible text remains the source of non-color meaning.
- [x] Chip boundaries are required across documentation themes.

## Responsive and Offline Behavior

- [x] Wide and 320 CSS pixel presentations are required.
- [x] Asset links must resolve locally in generated output.
- [x] JavaScript and network dependencies are prohibited.
- [x] UTF-8, LF, and mojibake checks are required.

## Notes

The checklist validates the contract. Implementation evidence is recorded in `quickstart.md`.
