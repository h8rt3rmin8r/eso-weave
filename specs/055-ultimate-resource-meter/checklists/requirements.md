# Requirements Quality Checklist: Ultimate Resource Meter

- [x] User value and scope are explicit.
- [x] Exact charge, maximum, front cost, and back cost have one source of truth.
- [x] Percentage-only ambiguity is resolved with a documented deviation.
- [x] Zero, missing, corrupt, unsupported, loss, and recovery states are defined.
- [x] Active-bar selection and unknown-bar behavior are defined.
- [x] Ready equality boundary and fixed placement are defined.
- [x] Quarter and cost marker geometry are measurable.
- [x] Theme colors and color-independent semantics are defined.
- [x] Automation exclusion is structural and testable.
- [x] Backward protocol compatibility is bounded by version.
- [x] Repository and live release verification are separated.
- [x] Success criteria are measurable and implementation-independent where practical.
