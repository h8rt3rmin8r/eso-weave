# S122 Documentation Model

No production schema or stored application state changes.

Each governed figure has an ID, owned asset, intrinsic canvas, source/output
page, accessible alternative, equivalent heading, critical prose/SVG anchors,
and current source authorities/update triggers. Nodes have unique `data-node`,
stage and geometry. Every visible connector has `data-edge`, `data-from`,
`data-to` and an orthogonal route. Branch labels identify their edge when used.

Catalog inputs converge; review branches to preview or explicit Live install.
Selection and rollback are distinct generations, not in-place database writes.
Local framing branches converge; state and fixed-database query authority are
parallel views, not stages that modify one another.

Manifest adds DIA-008 lifecycle and DIA-009 authority entries. Existing frozen
content obligations remain unchanged. Source/generated policy and browser
receipts include exactly eight flow assets and two new zoom/no-script cases.
