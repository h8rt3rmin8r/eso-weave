# S122 Research Decisions

## Catalog lifecycle

Decision: Pinned snapshots and collector captures are alternative inputs.
Rationale: `build_candidate_with_fetcher_and_cancel` switches input kinds before
normalization. Collector import does not mediate all pinned sources.
Alternative rejected: A serial source-to-collector chain would invent a dependency.

Decision: Separate review publication, origin acknowledgement and Live selection.
Rationale: `verify_candidate` verifies content/identity; `install` separately
requires origin acknowledgement, rechecks staged bytes and writes selection
atomically. `candidate_compatibility` keeps PTS preview-only. `rollback` reopens
the previous verified Live or bundled target, then advances generation.
Alternative rejected: An automatic candidate-to-selection arrow would misstate
both trust and channel behavior.

Decision: Label reports as redacted, not the entire candidate.
Rationale: SQLite can contain local-only collector values. Image objects remain
in a separate local cache; review does not grant redistribution rights.

## Local extension authority

Decision: Discovery and credential supply are distinct from admission.
Rationale: `DiscoveryRecord` contains endpoints/process/generation/schema, never
the token; `request_guard` applies bearer, effective Host, optional matching
Origin and body boundaries to all routes, including MCP initialization.
Alternative rejected: Historical shorthand calling discovery authenticated would
conflate non-secret filesystem discovery with authenticated service operations.

Decision: Both framing paths converge on shared authorities.
Rationale: `build_router` clones the same `SnapshotPublisher` and
`DatabaseQueryService` into HTTP and `PlayerStateMcp`. Snapshot parity uses
revision plus generation; database inventory and execution share two permits.
SQL handles close before results are framed. No transport-owned state exists.

## Documentation infrastructure

Decision: Reuse annotated static SVG, existing figure expansion and CDP runner.
Rationale: Source policy, exact generated bytes, paint/topology probes and
receipt mutation tests already cover offline/readability contracts. Extend
finite inventories and add equivalent/zoom checks for two figures.
Alternatives rejected: New rendering stack, viewer, theme or browser dependency.

Read-only research agents: `s122_catalog_research`, `s122_authority_research`.
Exact authority and update-trigger inventory: [contracts/figures.md](contracts/figures.md).
