# Data Model: Documentation Diagram Rendering Compatibility

## DiagramGeometryContract

- `id`: stable diagram identifier
- `page`: source Markdown page
- `outputPage`: generated HTML page
- `asset`: checked-in SVG path
- `outputAsset`: generated SVG path
- `width`: positive intrinsic CSS-pixel width
- `height`: positive intrinsic CSS-pixel height
- `viewBox`: origin and dimensions equal to width and height
- `alt`: meaningful primary image alternative
- `headings`: adjacent text-equivalent anchors
- `svgAnchors`: required visible labels
- `canvas`: opaque background dimensions and color

Invariant: source and generated bytes match, all geometry agrees, and visible anchors plus painted primitives are present.

## GeneratedFigureContract

- `container`: `.docs-flow-diagram`
- `control`: mdBook checkbox used by the existing zoom behavior
- `primaryImage`: local image with meaningful alt and responsive fill
- `expandedWrapper`: mdBook `.img-wrapper`
- `expandedImage`: same local source, decorative, intrinsic ratio preserved

Invariant: there is one announced image, one decorative generated clone, and neither image escapes its required container.

## CompatibilityObservation

- `diagramId`
- `surface`: generated-loopback (Pages and release embedding use separate delivery evidence)
- `theme`: navy or light
- `viewportWidth`: 320 or 1280
- `state`: normal or expanded
- `responseStatus`
- `contentType`
- `naturalWidth`, `naturalHeight`
- `renderedWidth`, `renderedHeight`
- `contained`
- `opaqueCoverage`
- `opaqueColorCount`
- `nonBackgroundCoverage`
- `result`

Invariant: every required observation passes explicit thresholds and identifies failures without screenshots or personal paths.

## RenderingReceipt

- `schemaVersion`
- `browser`
- `observations`
- `requests`
- `passed`
- `failures`

Invariant: success is emitted only when the full bounded matrix and all expected asset requests pass.
